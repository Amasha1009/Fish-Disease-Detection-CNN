# Deep Learning-Based Fish Disease Detection for Aquarium Fish Using CNN Models

## Project Overview

This project develops a deep learning system for detecting common diseases in aquarium fish using Convolutional Neural Networks (CNNs).

The research compares four CNN architectures:

- Baseline CNN
- VGG16
- ResNet50
- MobileNetV2

The objective is to identify the most effective model for fish disease classification under real aquarium conditions.

---

## Research Objectives

- Detect aquarium fish diseases from images.
- Compare CNN architectures.
- Evaluate models using Accuracy, Precision, Recall, F1-Score and ROC-AUC.

---

## Dataset

The dataset contains images of

- Healthy Fish
- Fin Rot
- White Spot Disease
- Skin Ulcer Disease

Images will be collected from public datasets and aquarium image sources.
